Frequently asked questions

Which numbers can I search with?

You can use a mobile number (11 digits, starting with 0 and without +92) or a 13-digit CNIC. Dashes are optional.

What if my number is not found?

Check the digits and try again. If the problem continues, call the helpline listed below.

Will the final system work on mobile?

Yes. The interface is fully responsive and is designed for phones first.
